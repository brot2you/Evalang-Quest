# Ev@lang Quest V5 — Accompagnement en français

Cette version conserve les questions, supports et réponses de l’entraînement en anglais, mais affiche les consignes générales, les encouragements, les rappels de règles, le journal et les explications de correction en français. La synthèse vocale demeure en anglais britannique. La progression est enregistrée localement avec la même clé que la V4.

Déposez **tout le contenu** de ce dossier à la racine de votre dépôt GitHub Pages.

Les estimations CECRL restent indicatives et ne correspondent pas à un résultat officiel Ev@lang.
