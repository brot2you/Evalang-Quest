# Ev@lang Quest V4 — Signal Arcade

Upload all files and the `assets/` directory to the root of the existing GitHub Pages repository. Do not change the site's URL if you want the browser's locally stored progress to remain accessible.

## What's new
- Completely revised arcade-style home screen, separate from the earlier Cozy village presentation.
- Ev@lang-inspired coral red with contrasting dark navy, turquoise accents and mission-console layout.
- Four direct mission entry points; CEFR passport, journal, 24 badges and reward shop retained.
- Respects reduced-motion preference and adapts to phones.

## Existing features retained
Original practice item bank, mixed diagnostic, adaptive demo heuristic, text-to-speech listening, XP and coins, badges, cosmetic shop, local data, learning journal and spaced revision.

**Important:** This is an independent training prototype. The CEFR placement model is not validated, and the current question bank is limited. This is not the official Ev@lang interface or assessment.
